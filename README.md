# FPGAmotherboard

KiCad files of motherboards for original x86 CPUs, where an FPGA is the whole
chipset: network-virtualised hard disk, NIC, a BIOS, no VGA.

| Folder | CPU |
|---|---|
| `socket3` | AMD Am5x86-P75 |
| `socket7` | Pentium MMX (P55C) |
| `socket370` | Pentium III (Coppermine) |
| `i386` | 80386SX |

Linked project: [FPGA-CPU](https://github.com/alphaonex86/FPGA-CPU) - the other
way round, an x86 CPU in an FPGA that plugs into an original motherboard's CPU
socket.
